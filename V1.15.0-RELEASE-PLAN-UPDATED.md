## Technical Details

### Event Bus Architecture

```python
# New component structure
PPXAIDEApp
    ├─ EventBus (blinker)
    │   ├─ on(event, handler)
    │   ├─ emit(event, **data)
    │   └─ Event logging
    │
    ├─ Engine Events → Bus
    │   ├─ STREAM_START/CHUNK/END
    │   ├─ CONSENT_FILE/SHELL
    │   ├─ TOOL_CALL/RESULT
    │   └─ ERROR
    │
    └─ Event Handlers (subscribed to bus)
        ├─ _on_stream_chunk()
        ├─ _on_stream_end()
        ├─ _on_consent_file_request()
        └─ _on_consent_shell_request()
```

**Before (complex):**
```python
async def _handle_event(self, event: Event):
    if event.type == EventType.CONSENT_REQUEST:
        future = asyncio.Future()  # Complex!
        self._pending_consent = future
        response = await future
```

**After (simple):**
```python
async def _on_consent_file_request(self, sender, data, **kwargs):
    """Simple handler - event bus decouples."""
    result = await self._show_consent_dialog(data)
    # No Future needed!
```

**Benefits:**
- ✅ Visibility - All events logged
- ✅ Debugging - Can see event flow
- ✅ Simplicity - No Future coordination
- ✅ Testability - Mock event bus
